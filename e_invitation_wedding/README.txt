ROYAL KHMER WEDDING INVITATION

PROJECT STRUCTURE
- index.html
- css/style.css
- js/script.js
- assets/ (add your own images and wedding music here)

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server (recommended), or open it directly in a browser.

CUSTOMIZE YOUR WEDDING
Open js/script.js and edit the WEDDING object near the top:
- bride: bride's name
- groom: groom's name
- date: wedding date/time in Cambodia UTC+7 format
- venue: wedding venue name
- address: full venue address
- time: ceremony time
- mapQuery: Google Maps search location

IMAGE AND MUSIC FILES
Add these files inside assets/:
- temple-entrance.jpg
- love-story.jpg
- prewedding-1.jpg through prewedding-6.jpg
- wedding-song.mp3 (optional)

The ABA QR image can be previewed with the existing upload control. The music upload and play/pause controls are preserved. For a published invitation, put your chosen music file in assets/wedding-song.mp3 so guests hear the same song.

FUNCTIONALITY PRESERVED
- Animated envelope; click Open Invitation to begin.
- Background music starts after the user clicks Open Invitation; music loops and can be paused/resumed.
- Countdown updates every second.
- Scroll reveal animations and normal page scrolling (scrollbar hidden).
- Love story and six-photo gallery.
- Responsive Google Maps embed and external map link.
- ABA QR image upload and preview.

NOTE
The default wedding names, date, venue and map location are sample values. Update them before sharing the invitation. Google Fonts require an internet connection; fallback fonts are included.
